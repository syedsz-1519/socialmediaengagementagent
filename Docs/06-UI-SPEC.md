# NEXA — UI Specification

**Version:** 1.0

---

## 1. Design Direction

NEXA should look like a polished modern AI SaaS.

Style:

- clean;
- professional;
- intelligent;
- minimal;
- desktop-first;
- fully responsive;
- not a generic ChatGPT clone.

---

## 2. Primary Screens

### Screen 1 — Dashboard

Purpose:

Show that NEXA understands the brand.

Sections:

- brand overview;
- audience summary;
- top learned insights;
- recent learning;
- recommended next action;
- CTA to generate content.

---

### Screen 2 — Memory

Purpose:

Make Hindsight visible.

Display:

```text
🧠 Brand Memory

Audience Insights
Content Patterns
Brand Preferences
Strategic Beliefs
```

Each memory can show:

- insight;
- confidence;
- evidence;
- recency;
- supporting experiences.

---

### Screen 3 — Generated Content

Purpose:

Show the value of memory.

Display:

```text
Recommended Reel

Hook
Concept
Script
Caption
Hashtags
Posting time

Why NEXA chose this
Memories used
Confidence
```

---

## 3. Learning Timeline

Can appear within Memory rather than being a separate top-level screen.

Example:

```text
Day 4
Educational content identified

Day 12
Generic promotions underperform

Day 21
Problem-based hooks emerge

Day 30
Strategy updated:
Problem + education
```

---

## 5. Dashboard Empty/Fresh State

Fresh-brand mode should demonstrate:

```text
Not enough audience history yet.

NEXA needs more interactions before
making strong strategic claims.
```

This reinforces that the product actually learns over time.

---

## 6. Before/After Demonstration

Optional but recommended:

```text
WITHOUT MEMORY

Generic:
"5 ways to improve your website"

WITH NEXA MEMORY

Personalized:
"Your homepage is losing customers before
they ever see your services."

Why:
Problem hooks + business pain points
performed better for this audience.
```

---

## 7. Responsive Requirements

The UI must work on:

- desktop;
- tablet;
- mobile.

Desktop remains the primary judge-demo experience.

---

## 8. UI Rules

Avoid:

- excessive animations;
- unnecessary dashboards;
- fake analytics;
- decorative complexity;
- huge amounts of text.

Prioritize:

- hierarchy;
- clarity;
- memory visibility;
- recommendation reasoning.
